# VaultRun brand assets

Canonical files for [vaultrun.dev](https://vaultrun.dev) and social / GitHub use.

## Mark

Terminal prompt inside a square frame: `>_`

| File | Use |
|------|-----|
| `mark.svg` / `mark.png` | Dark mark (default) |
| `mark-light.svg` / `mark-light.png` | Light backgrounds |
| `mark-transparent.svg` | Overlays (no fill) |
| `favicon.svg`, `favicon-32.png`, `favicon-64.png` | Browser tab |
| `apple-touch-icon.png` | iOS home screen |
| `icon-192.png`, `icon-512.png` | PWA / app icons |
| `badge.svg` | README / markdown badge |

## Lockup & wordmark

| File | Use |
|------|-----|
| `lockup.svg` / `lockup.png` | Mark + VAULTRUN (dark) |
| `lockup-light.svg` / `lockup-light.png` | Mark + VAULTRUN (light) |
| `wordmark.svg` / `wordmark-light.svg` | Text only |

## Social / video

| File | Size | Use |
|------|------|-----|
| `og.png` | 1200×630 | Open Graph / LinkedIn / X link preview |
| `social-square.png` | 1080×1080 | Profile / square posts |
| `video-endcard.png` | 1920×1080 | Demo video end card |

## Rules (short)

- Prefer SVG for UI; PNG for social platforms that need raster.
- Do **not** invent customer logos or star counts next to the mark.
- Keep palette near `#0a0a0a` / `#e8e8e8` — no purple glow variants.
- Full guidance: [`docs/brand.md`](../../docs/brand.md)
- Copy pack: [`docs/content-kit.md`](../../docs/content-kit.md)
