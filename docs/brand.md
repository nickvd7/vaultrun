# VaultRun brand guidelines

Status: **2026-07** · Assets: [`site/brand/`](../site/brand/)

## Positioning (one line)

> Self-hosted secure runtime for AI agents.

Longer: VaultRun runs agent tools in isolated Docker sandboxes on *your* infrastructure — MCP-native, HMAC-signed audit trail, no SaaS telemetry.

## Logo

**Mark:** square frame + terminal prompt `>_`  
**Wordmark:** `VAULTRUN` (all caps, monospace / geometric)  
**Lockup:** mark left, wordmark right

| Do | Don't |
|----|-------|
| Use dark mark on dark UI | Stretch or rotate the mark |
| Use light mark on white slides | Add drop shadows / neon glow |
| Keep clear space ≈ 1/4 mark width | Place next to fake customer logos |
| Link to vaultrun.dev or GitHub | Recolor to purple / brand-of-the-week gradients |

## Color

| Token | Hex | Use |
|-------|-----|-----|
| `--bg` | `#0a0a0a` | Background |
| `--fg` | `#e8e8e8` | Primary text / mark |
| `--dim` | `#8a8a8a` | Secondary text |
| `--line` | `#262626` | Rules / borders |
| `--faint` | `#555555` | Hints |

Accent = high-contrast white on black. No secondary brand purple.

## Typography

Site and decks: **monospace** stack (`SF Mono`, `JetBrains Mono`, `Menlo`, `Consolas`).  
Headlines may be bold monospace; body stays readable at 14–16px.

## Voice

- Direct, technical, calm — founder / platform eng tone
- Prefer “on your infra” over “enterprise-grade AI platform”
- Early product: **no invented social proof** (stars, quotes, logos)
- Open core vs Enterprise SSO: always separate clearly
